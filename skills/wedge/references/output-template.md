## 4. Cheapest test

The next action should reduce uncertainty, not merely create activity.

```yaml

```

## 5. 7-day / 30-day path

### 7 days

- first proof;
- first external signal;
- first interviewable story.

### 30 days

- deeper proof;
- external validation;
- one reusable narrative;
- target-company list.

## 6. Kill criteria

List explicit evidence that should make the user stop or pivot.

Good kill criteria are observable:

- target companies do not value the work;
- benchmark result is trivial or non-reproducible;
- supply is already highly saturated;
- prerequisite learning cost exceeds available time;
- another wedge has materially better evidence ROI.
