# Career Alpha Roadmap

Career Alpha is intentionally small at the skill-entry layer. The roadmap focuses on making the existing loop more useful rather than adding endless commands.

- [x] Local Workbench

- [x] Claude Code marketplace manifest
- [x] Agent Engineer end-to-end case
- [x] AI Product / Quant / Robotics case library

## v0.4 — Research & Market Intelligence

- [ ] Structured market-signal snapshots with date / source / confidence
- [ ] Re-check workflow for stale `/radar` assumptions
- [ ] Company / role hypothesis comparison view
- [ ] Evidence ROI history across completed missions
- [ ] Feedback-weighted wedge scoring
- [ ] Optional integrations for job posts / GitHub evidence / recruiting mail while preserving privacy boundaries

## Non-goals

Career Alpha is not trying to become:

- a fake-experience generator;
- a generic resume template marketplace;
- a job-board scraper with no evidence layer;
- a leaderboard that pretends one career path fits everyone;
- a system that automatically turns weak evidence into strong claims.

The product thesis remains:

> **Find the missing fact with the highest career leverage, build it honestly, and let real market feedback update the next move.**
