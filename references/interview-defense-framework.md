# Interview Defense Framework

用于 `/interview` 对简历主张做连续追问。

## Five-layer drill

对每条强主张至少覆盖：
1. **Fact** — 你具体做了什么？
2. **Mechanism** — 它为什么有效？
3. **Trade-off** — 为什么没选其他方案？
4. **Evidence** — 你怎么证明结果？
5. **Boundary** — 哪部分不是你做的？

进阶继续问：
- failure case
- regression
- scale
- reproducibility
- hindsight

## Risk ranking

优先追问：
- 精确数字；
- “主导 / owner / founder”；
- 高复杂度架构；
- 明显像 AI 写出来的漂亮 bullet；
- 与用户基础背景跨度很大的技能；
- 比赛 / 奖项 / production deployment。

## Scoring

每项 1–10：
- Technical Depth
- Ownership
- Evidence
- Decision Quality
- Trade-off Awareness
- Failure Understanding
- Communication

## Downgrade rule

如果用户在两轮补问后仍无法解释某项核心机制或证据，应建议：
1. 补知识；或
2. 补实验；或
3. 降低简历表述强度。

不要教用户用模糊话术掩盖事实缺口。
