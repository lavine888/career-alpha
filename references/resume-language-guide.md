# Resume Language Guide

用于 `/position` 将证据翻译成求职语言。

## Bullet formula

优先使用：

```text
Action → System/Capability → Value → Result → Scope/Boundary
```

示例：

差：
> 参与 Agent 项目开发，负责模型调用和优化。

较好：
> Built a tool-using agent evaluation pipeline and introduced retry/context policies, improving completion from 61% to 78% on a defined 50-task benchmark.

前提是这些数字和 ownership 已在 ledger 中有证据。

## Verb strength

### Strong
Led / Owned / Designed / Architected / Shipped

只有用户对关键决策、执行或结果承担明确责任时使用。

### Medium
Built / Implemented / Developed / Drove / Coordinated

适合能明确说明个人交付，但并非整体 owner 的情况。

### Conservative
Contributed to / Supported / Collaborated on

适合团队边界不清或仅参与部分工作。

## Avoid

- 大量“熟悉、了解、掌握”；
- 把技术栈堆成一句话；
- 没有上下文的百分比；
- “赋能、闭环、抓手”等无法验证的空词；
- 用 title 替代真实职责。

## Channel adaptation

### Resume
高信息密度，强调动作、结果和能力。

### HR opening
先说身份和方向，再给 1 个可信证据，最后给明确交流意图。

### Founder / Hiring Manager DM
少写“我非常感兴趣”，多写“我最近解决了与你们问题相邻的什么问题”。

### Interview intro
优先讲职业主线与 2–3 个可展开证据，不按时间流水账念简历。
