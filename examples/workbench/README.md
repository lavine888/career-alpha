# Workbench Example Bundles

These JSON files can be imported directly into `assets/career-alpha-workbench.html` using **Import JSON**.

| Bundle | Career wedge |
| --- | --- |
| `agent-engineer.json` | Agent Reliability / Evaluation |
| `ai-product-manager.json` | AI Workflow + Evaluation PM |
| `quant-researcher.json` | Robustness-first Systematic Research |
| `robotics-engineer.json` | Robotics Evaluation + Failure Recovery |

## How to use

1. Download or clone the repository.
2. Open `assets/career-alpha-workbench.html` in a browser.
3. Click **Import JSON**.
4. Select one of the bundles in this directory.
5. Edit the imported assumptions, evidence and pipeline as if they were your own career hypothesis.

The examples are fictional and educational. Metrics and outcomes must not be copied into a real resume unless the user has actually reproduced and verified them.
